# 蓝桥杯第十六届嵌入式省赛 — 省一等奖代码

基于 STM32G431RB 开发板，完成第十六届蓝桥杯嵌入式设计与开发省赛全部功能要求，获省一等奖。

## 硬件平台

- **主控**：STM32G431RBT6 (Cortex-M4F @ 80MHz，含 FPU 和 DSP 指令集)
- **板载外设**：LED × 8、按键 × 4、LCD 显示屏、电位器 ADC、DAC 输出、UART 串口

## 实现功能

| 模块 | 功能要求 |
|------|---------|
| 按键控制 | 多按键组合触发不同模式切换 |
| LCD 显示 | 显示界面切换、参数设置、数据刷新 |
| ADC 采集 | 多通道模拟量采集（板载电位器 + 外部信号） |
| DAC 输出 | 根据 ADC 输入或预设波形生成模拟输出 |
| UART 通信 | 串口收发指定格式数据帧 |
| LED 指示 | 状态指示灯、PWM 呼吸灯效果 |

## 技术要点

- STM32CubeMX 配置 + Keil MDK 开发
- HAL 库外设驱动（ADC、DAC、TIM、UART、GPIO）
- LCD 驱动（80 并口）
- 按键状态机消抖
- 中段优先级管理

## 使用

用 Keil MDK 打开 `Project/` 目录下的 `.uvprojx` 文件，编译下载到 CT117E-M4 开发板即可。
